# Spec: Измеримое облегчение действующих DSH-плагинов (v4, Pro review)

## 1. Intent & Invariants
- Цель — доказать или отвергнуть улучшение пользовательского отклика конкретного текущего DSH-плагина минимальной настройкой либо маленькой правкой **существующего собственного** кода. Никаких форков, переписывания, новых зависимостей, патча core, отключения функции или изменений production в ходе этого согласования. Итог `NO SAFE MEASURABLE CHANGE` — полноценный успех исследования.
- `performance-baseline-web-015.json` — разведка, **не** acceptance baseline: 60 graph entries, 12,173,521 raw JS bytes, seven included non-core client modules 1,015,005 bytes (8.3%); core PDF preview 6,888,478 raw bytes и ~3.19 MB gzip; Host RSS ~926 MiB без атрибуции. Graph presence не доказывает mount/работу плагина; размер не равен задержке. PDF preview и Files сохраняются; core bottleneck → upstream issue, не fork/disable.
- R0 — static read-only. R1 — observational live browser только после отдельного согласия на existing authenticated CDP. C1 — controlled A/B только на отдельно разрешённом isolated canary. P1 — любое изменение production, установка и рестарт требуют новой человеческой санкции. Pro `OK` подтверждает методику, не действия.

## 2. Interface / Data Contract
```text
R0 files/graph/hash/timer inventory → candidate hypotheses only.
R1 authorized live observation → sanitized aggregate timings, no causal verdict.
C1 authorized isolated canary → locked H0, validated A/A, locked H1, single A/B.
P1 separate approval and artifact/restart plan; never implicit.
```
- **R1 privacy:** только одобренный existing authenticated CDP target. Collector не включает response bodies, Network extra-info, DOM snapshots, screenshots, console payloads, cookies/headers; unknown endpoints/fields discarded IN MEMORY before write. Persist only predeclared normalized route classes, aggregate status/timing/bytes/task cost; no raw live trace, no event payload stdout/stderr. CDP metadata may be transiently visible locally — explicitly disclose before consent; zero-transient-exposure → omit network lane. C1 raw trace only with independent approval and non-sensitive fixture.
- **Timing and scenarios:** `http-cache-disabled` only disables HTTP cache; `http-cache-warm` enables it, with priming excluded. Cookies/storage and Host PID unchanged in R1; service worker/CacheStorage/code cache/browser age recorded/fixed; browser-process-cold and Host-cold only C1 with approval. Live Host `/proc`/systemd CPU/RSS/PSS/I/O/FD metrics are observational, NEVER event-loop delay; `node:perf_hooks` only in separately approved canary. S1 navigationStart → `max` of three frozen DOM milestones (conversation visible, sidebar control usable, input interactable); S2 click → terminal data/empty/error; S3 tab activation → first paint after frozen terminal predicate; S4 idle ≥10 min → requests/encoded bytes/main-thread ms/long tasks per minute. Before any C1 run, freeze per-scenario selector version, monotonic clock, start/end, timeout, symmetric failure/exclusion rules; timeout/crash/error counted, not silently dropped.
- Timers are hypotheses only: groups visible config 15s, OpenViking status active 2.5s/idle 15s, Limits/Keys 60s while mounted, Fleet Cleaner 15s only visible, mobile debug timer only with query flag. Native sidebar renders active body per pane; account for two panes/float/module-level timers, actual requests and cleanup. Visibility change only for demonstrated continued hidden requests, dedupe only for measured overlap, interval only via existing setting with proven freshness. Attribution trace only safe C1; timing acceptance lane low overhead/no full trace. R1 never compared causally with C1.
- **Two-stage lock for each C1 hypothesis:** Before first A/A, hash **H0** with exact immutable A/B artifact digests, one primary scenario + metric + direction, exactly one primary cache stratum (`http-cache-warm` **or** disabled; other descriptive only), practical threshold `δ`, selector/timing/reset, all guardrail non-inferiority margins/windows/estimators/failures, A/A equivalence tolerance `0<ε_AA<δ` and order/drift/dependence/carryover checks, deterministic N rule plus N_max, pair-bootstrap construction, randomization and analysis seeds. No δ/endpoint/stratum/method tuning from A/A or B. Post-H0 change invalidates A/A and requires a fresh untouched A/A dataset.
- A/A uses **the same artifact-switch/reset path** as future A/B: ≥3 discarded warmups for each measured condition × cache stratum, then ≥10 randomized paired A/A blocks. Pass requires 95% CI pseudo-effect A1−A2 entirely within [−ε_AA,+ε_AA], no correlated failures/order/carryover, and predeclared drift/dependence/reset checks pass. A/A supplies dispersion only to H0 deterministic sample-size rule; if fail or N>N_max, stop before B. Fix N≥15 pairs for **the one primary stratum**, calculate **H1=H0+A/A result+fixed N** before first B.
- Each A/B pair is one A and one B with independently seeded AB/BA order. Each run starts at the same condition-neutral checkpoint (browser storage/service worker/CacheStorage, server fixture, timer/module lifecycle); otherwise use fresh isolated clones per run or declare non-confirmable. H0 defines paired improvement estimator, two-sided percentile paired-bootstrap 95% CI over **whole pair deltas**, 10,000 replicates with fixed independent analysis seed, tie/failure convention, and predeclared serial-dependence/drift threshold; iid resampling invalid if A/A dependence check fails, so **stop**, not post-hoc change method. Complete sample size N fixed; never extend after inspecting B. Publish raw pairs, randomized order, failures, median paired delta, descriptive p50/p95 and MAD; descriptive stratum cannot accept B.
- **Decision:** accept one B only if *lower* 95% CI bound of its predeclared primary improvement exceeds `δ` and every functional/privacy/error/freshness/resource guardrail passes exact or predeclared non-inferiority bounds. Otherwise NO SAFE MEASURABLE CHANGE. No cherry-picking of alternate candidate or stratum: each new hypothesis needs untouched H0/A/A/A/B dataset and separate operator consent; no core edit/disable.

## 3. Verification Checklist (Definition of Done)
- [ ] R0 hashes and Host/browser/fixture/cache context recorded; graph/raw-byte baseline not misused as causal or user latency evidence.
- [ ] R1 only after explicit consent to transient CDP visibility and privacy contract, otherwise skipped. No production changes, raw trace, secrets, session IDs or extra HTTP load.
- [ ] C1 only after explicit consent; H0 before A/A, equivalence/order/dependence/reset gate passed, fixed N and H1 before B; one primary cache stratum, complete-pair bootstrap, no optional stopping/carryover or condition-dependent exclusions.
- [ ] B improves beyond precommitted `δ` with lower 95% CI and no predefined guardrail regression, else NO SAFE MEASURABLE CHANGE. Functional behavior retained; no fork/rewrite/core disable.
- [ ] Pro gives explicit `OK` to the method only. Any authenticated measurement, canary, edit, release, install or restart remains a separate human decision.
