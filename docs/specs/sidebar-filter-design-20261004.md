## Design read
Utility sidebar for active DSH operators, native restrained style. ENERGY 1 / RHYTHM 1 / MOTION 1. Inherit host typography and semantic theme tokens. Full-width stacked scope controls prevent ragged edges and clipped labels. A dedicated compact tools row separates color/recency from scopes. One reset in the summary avoids duplicate controls. Empty filtered view explicitly says filters have no matches, rather than claiming the workspace list is empty. Native selected/focus states and menus; no gradients, shadows or decorative cards.
