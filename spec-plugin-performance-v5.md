# Spec: Безопасное измеримое облегчение действующих DSH-плагинов (v5, Pro review)

## 1. Intent & Invariants
- Цель — найти действительно улучшающую пользовательский отклик настройку или малую правку **существующего собственного** DSH-плагина, без форков, переписывания, новых зависимостей, core edits или потери функции. Допустимый итог: `NO SAFE MEASURABLE CHANGE`. GitHub, DSH production и пользовательский браузер не меняются из-за технического Pro-review.
- `performance-baseline-web-015.json` — разведка: 60 graph entries, 12,173,521 raw JS bytes; семь included non-core modules 1,015,005 bytes (8.3%) не доказанно active/mounted; core PDF preview 6,888,478 raw bytes (gzip ~3.19 MB) и Host RSS ~926 MiB не равны plugin-attributed latency. Core document preview не отключать; измеренная core-проблема уходит upstream.
- R0 static read-only; R1 строго пассивное наблюдение уже существующей авторизованной вкладки только с отдельным человеческим CDP-consent; C1 изолированный Host/browser canary, управляемые действия и A/B только с отдельным human consent; P1 production change/restart по ещё одному отдельному решению. Ни один из них не включается автоматически после Pro-OK.

## 2. Interface / Data Contract
```text
R0: observed manifests, installed hashes, graph/timer inventory -> hypotheses.
R1: passive existing actions, safe in-memory aggregates, no browser mutations.
C1: approved isolated canary with H0 before A/A, one A/A analysis, H1 before B,
    fixed paired A/B and preregistered abort/acceptance policy.
P1: separate operator approval only, outside this review.
```
- **Privacy R1:** только одобренный existing authenticated CDP target; no response bodies, Network extra-info, raw traces, headers/cookies, DOM snapshots/screenshots/console payloads. Allowlist collector in memory emits aggregate route class/status/timing/bytes/task cost; unknown fields/endpoints discarded **before write**, no event payloads in logs. Transient metadata visibility disclosed in consent; zero-transient requirement → omit R1 network lane. R1 observes only naturally occurring operator actions and existing cache: **no** `Network.setCacheDisabled`, cache priming/clear, scripted navigation/click/reload, measurement-induced HTTP requests. Cache comparisons/scripts only C1. No live inspector, `perf_hooks`, plugin change or traffic flooding.
- **Metric contract:** `http-cache-disabled` means only HTTP cache disabled, not browser-process-cold or Host-cold; separate warm stratum excludes priming. C1 freezes cache, service worker, CacheStorage/code-cache/browser age; R1 merely records their observed state. Live Host CPU/RSS/PSS/I/O/FD telemetry from existing sources, no event-loop-delay claim. Event-loop delay/ELU optional only within separately authorized instrumented canary. S1 navigationStart → maximum of predeclared Conversation-visible, sidebar-usable and input-interactable milestones; S2 naturally clicked plugin tab → first data/valid empty/error; S3 tab activation → next paint of frozen terminal predicate; S4 ≥10 min naturally idle → per-minute requests/bytes/main-thread tasks. Error/timeouts remain failures, selectors/clock/paint/timeout frozen before trials.
- Timer list generates hypotheses only: workspace config visible 15s; OpenViking status active 2.5/idle 15s; Limits/Keys mounted 60s; Fleet 15s only visible; mobile debug 1.5s only query flag. Native right sidebar renders active tab body per pane, but count two panes/floats and cleanup. No interval increase, request dedupe or visibility guard unless actual workload attribution, equivalent overlap and freshness requirement prove it. Full tracing only non-sensitive C1 attribution lane; low-overhead timestamps/DOM milestones for C1 acceptance lane; no causal comparison of live R1 to canary C1.
- **C1 H0 lock BEFORE first A/A block:** hash immutable A and one candidate B artifacts plus *entire* measurement environment: exact DSH/profile/lock/patch/plugin graph digests, Node/runtime, browser build, harness artifact, fixture snapshot, viewport/device scale, cache/service-worker/storage/code-cache policy, flags, Host/browser process-lifetime policy, machine resources/background workload. H0 fixes one primary scenario/metric/cache stratum (other descriptive only), direction and practical δ; selector/clock/timeout/failure/exclusion/reset rules, per-guardrail non-inferiority margins/windows/estimators, exact A/A size `N_AA >=10`, discarded warmup count, randomization schedule/seed, A/A equivalence tolerance `0<ε_AA<δ`, order/drift/dependence/carryover checks, deterministic f(A/A dispersion,δ) and N_max; CI variant (two-sided percentile 95% paired-bootstrap over complete pair deltas, 10,000 replicates, analysis seed) and tie handling. No protocol edit after observing A/A; any H0/environment/harness change requires new untouched A/A.
- **C1 A/A → H1:** ≥3 discarded warmups per condition × measured cache stratum; exactly H0-locked `N_AA` randomized paired A/A blocks via same artifact-switch and condition-neutral reset as A/B; evaluate once after all complete pairs, **no peeking/prolonging** for a favorable CI/dispersion. Only predeclared condition-blind technical invalidation may repeat runs, never observed latency. A/A passes only if whole-pair pseudo-effect 95% CI inside [−ε_AA,+ε_AA] plus zero condition-correlated failures and predeclared order/drift/dependence/carryover/reset gates; else STOP. Then derive fixed N≥15 for primary stratum mechanically from H0 f, require N≤N_max, hash H1=H0+A/A result+N before any B; H1 cannot replace H0 fields.
- **C1 confirmatory:** exactly N paired AB/BA blocks, order independently randomized from H0 seed; each run from same condition-neutral browser/Host/fixture checkpoint. If full reset cannot be shown, use fresh isolated clones per run or declare non-confirmable. Publish every raw pair, order, failure, descriptive p50/p95/MAD; apply H0-locked drift/serial-dependence/order/carryover diagnostics **both A/A and A/B**; any A/B invalidation → inconclusive, never accept B or change CI method post hoc. Primary CI resamples complete pairs, not independent A/B observations. Accept B only if lower 95% CI of predeclared primary improvement >δ AND all privacy/function/freshness/error/resource guardrails pass exact or predeclared non-inferiority bounds; otherwise NO SAFE MEASURABLE CHANGE. No alternate candidate/metric/cache stratum chosen after seeing B.

## 3. Verification Checklist (Definition of Done)
- [ ] R0 evidence remains reconnaissance, no latency inference from bundle size/poll frequency, deployed version hashes match read-only live graph.
- [ ] R1 separately authorized and strictly passive; no raw sensitive trace, new HTTP traffic, scripted action, cache mutation or production modification; absent consent means skip R1.
- [ ] C1 separately authorized: H0/environment and exact A/A N fixed before A/A, one equivalence check, H1 fixed before B, primary stratum and predeclared CI; invalid drift/reset/dependence on either A/A or A/B prevents acceptance.
- [ ] Confirmatory B passes lower CI>δ, all guardrails and behavior-preserving checks or declare `NO SAFE MEASURABLE CHANGE`; no core patch/fork/rewrite.
- [ ] Pro explicitly gives OK to method only; authenticated CDP, canary, edits, installation and restart each remain separately human-approved.
